# 📊 ClientDash

> Dashboard web para gerenciamento e acompanhamento de clientes.

O **ClientDash** é uma aplicação web desenvolvida para centralizar informações de clientes e apresentar indicadores importantes de forma clara e organizada.

O projeto simula um ambiente administrativo no qual é possível acompanhar métricas, consultar clientes e realizar o cadastro de novos clientes.

## 🚀 Demonstração

🔗 **Acesse o projeto:**
https://client-dashboard-phi-ruby.vercel.app/

## 📌 Sobre o projeto

O ClientDash foi desenvolvido como um projeto de portfólio com o objetivo de praticar e demonstrar conhecimentos em desenvolvimento web, criação de interfaces administrativas e organização de informações em dashboards.

A aplicação possui uma interface voltada para gerenciamento de clientes, apresentando informações importantes de maneira visual e facilitando a consulta e o cadastro de novos registros.

## ✨ Funcionalidades

* 📊 Dashboard com indicadores gerais
* 👥 Visualização de clientes
* 🔎 Busca de clientes
* 🔽 Filtro por status
* ➕ Cadastro de novos clientes
* 📋 Listagem com nome, e-mail, telefone, status e data de cadastro
* 📈 Exibição de indicadores de desempenho
* ⚙️ Área de configurações
* 📱 Interface adaptada para utilização em diferentes dispositivos

## 🖥️ Dashboard

O painel apresenta informações como:

* Total de clientes
* Clientes ativos
* Novos clientes
* Receita estimada
* Variação dos indicadores
* Lista de clientes cadastrados

Essas informações permitem uma visualização rápida do estado atual da base de clientes.

## 👥 Gerenciamento de clientes

A aplicação possui uma área específica para gerenciamento dos clientes.

É possível:

* Consultar clientes cadastrados
* Pesquisar pelo nome
* Filtrar clientes por status
* Visualizar informações de contato
* Cadastrar novos clientes
* Definir o status do cliente

### Dados apresentados

| Informação       | Descrição                            |
| ---------------- | ------------------------------------ |
| Cliente          | Nome do cliente                      |
| E-mail           | E-mail de contato                    |
| Telefone         | Telefone do cliente                  |
| Status           | Situação atual do cliente            |
| Data de cadastro | Data em que o cliente foi cadastrado |
